# 🧮 Configurator

## 📌 What

Browser-only rack configurator published at <https://homeracker.org/configurator/>. Define a rack, preview it, and get a bill of materials.

## 🔧 How

```sh
cd configurator
npm ci
npm run dev      # local dev server
npm run check    # eslint + tsc + vitest
npm run build    # static bundle in dist/
```
